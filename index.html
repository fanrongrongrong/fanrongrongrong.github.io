难点

普通 AI 聊天没有连续生活：记不住事，也不会主动，聊久了还容易变味。

我怎么解决

  • 用作息状态机驱动睡眠、勿扰和醒后补回消息，由模型决定是否主动联系
  • 按任务编排 Claude、DeepSeek、gpt-image-2 和百炼语音，兼顾体验和成本

人格复刻系统

  • 88,282 条消息

  • 留出集 + 盲测
数据和代码不公开

用 88,282 条真实消息，拆解一个人的说话方式。

难点

纯人设 Prompt 只能模仿表面语气，记不住真实经历，也说不清到底像不像。

我怎么解决

  • 用 BM25 检索 7,866 个会话窗口，查不到就拒绝编造
  • 按时间留出最后 10% 作测试集，设计盲测流程，用评测替代自我感觉

wechat-mac-auto-export

主流工具失效时，我换了一条路

  • 系统 API 层方案
  • 无人值守
  • 公开仓库
GitHub ↗

不猜内存特征，直接在系统函数层拿到密钥。

难点

常见工具靠扫描内存特征取密钥，微信小版本一更新就可能失效。

我怎么解决

  • 用 Frida Hook 系统的 CCKeyDerivationPBKDF，在密钥派生时直接拿到结果
  • 打通解密、导出 JSONL 和 launchd 定时任务，做到无人值守
  • 加入登录界面安全阀，并把原理和踩坑过程写成公开教程
  • Python
  • Frida
  • SQLCipher
  • launchd
